# 今日进账 v1.0.0

SwiftUI 原生 iPhone 工具，最低 iOS 17，arm64。

## 功能
- 小/中尺寸桌面小组件显示今日收入、计薪状态和更新时间。
- 月薪或日薪，自定义上下班、午休及每周工作日；默认 09:00–18:00。
- 今日页面可见且 App 活跃时每秒计算；暂停/恢复、整天无薪请假及撤销。
- 月度累计及每日明细；历史工资按生效版本计算。
- 本地保存，无联网、广告、统计 SDK 或后台常驻；小组件通常五分钟一个快照，实际显示受系统调度。

## 下载与安装
下载 `today-earnings-1.0.0.ipa`；对应 `.sha256` 可用于校验。

**这是 ad-hoc 临时签名包，不是 App Store 分发签名，也不是签名后立即可安装的开发包。** 需要侧载工具或自己的开发团队重签名主 App 与扩展，并授予相同的有效 App Group。免费个人团队或某些侧载工具可能不支持该权限；如共享容器不可访问，App 会明确报错，无法保存设置。请勿把下载或本机签名校验通过当成已通过 SideStore 真机安装测试。

## 验证与已知限制
- 独立 iOS SDK 编译主 App 与 Widget 扩展通过；产物检查为 iOS arm64，最低 iOS 17。
- 临时签名严格校验、IPA ZIP CRC 与包结构校验通过。
- 19 项独立 Swift 计算校验通过。
- 尚未真机/模拟器运行验收，界面、耗电、实际运行内存、小组件展示及刷新待验证。
- 普通 iOS 小组件不保证秒刷/分钟刷新；App 内才有每秒变化。
- 不自动计算税费、节假日、调休、加班；暂不支持跨夜班次。时区随设备变化，建议保持稳定。
- 初版暂未提供自定义 App Icon。
